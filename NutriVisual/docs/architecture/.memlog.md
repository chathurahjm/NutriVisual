- (constraint) Food database stored in src/data/foods.json with 128 items containing id, name, category, and image URL
- (constraint) Project environment already contains GEMINI_API_KEY in .env and @google/generative-ai in package.json
- (assumption) [ASSUMPTION] Verification architecture must be tiered: Tier 1 (deterministic URL health & duplicate collision check, 0 cost) and Tier 2 (multimodal AI vision semantic verification)
- (assumption) [ASSUMPTION] An audit cache must persist verification state to avoid repeating costly API calls on images that have already been validated and unchanged
- (decision) AD-1: Tier 1 deterministic audit tests URL protocol, HTTP HEAD reachability (200 OK), valid image MIME, and unallowed duplicate URL collisions across non-variant foods
- (decision) AD-2: Tier 2 semantic vision audit uses Gemini Flash structured output with inline image base64/fetch to verify visual identity against food name
- (decision) AD-3: Cache key uses SHA-256 hash of food id + image URL stored in src/data/image-audit-cache.json to guarantee cache invalidation whenever an image URL changes
- (decision) AD-4: Exposed via npm scripts (npm run test:images for full tiered test, npm run test:images:quick for Tier 1 static only)
